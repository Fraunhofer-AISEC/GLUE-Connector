The `schema/` directory contains the json schemas for the CMC Json API.
The original files can be found in the [CMC repository](https://github.com/Fraunhofer-AISEC/cmc/tree/v0.10.3/doc/api/json) and are licensed under the Apache License 2.0.
Documentation for the API is located [here](https://github.com/Fraunhofer-AISEC/cmc/blob/v0.10.3/doc/cmcd-api.md).
